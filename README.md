# FaceFusion Mobile NCNN Models

Unofficial NCNN conversions of models used by FaceFusion Mobile. Binary model files are distributed through GitHub Releases, not Git history.

## HyperSwap 1b 256

The NCNN files are converted from [FaceFusion's original `hyperswap_1b_256.onnx`](https://huggingface.co/facefusion/models-3.3.0/blob/main/hyperswap_1b_256.onnx). FaceFusion identifies this model as `ResearchRAIL` in its [model metadata](https://github.com/facefusion/facefusion/blob/master/facefusion/processors/modules/face_swapper/core.py). Follow the upstream model and application terms, including their use restrictions. This repository is not affiliated with FaceFusion.

See Releases for the converted files and their SHA-256 checksums.
